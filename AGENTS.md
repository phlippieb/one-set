# Agent Instructions

## Delivery Increments

- Read `plan.md` before starting implementation work.
- By default, implement only one unchecked `plan.md` item at a time.
- Keep changes and validation focused on that item; do not continue into adjacent items just because they are related.
- After completing the item and its focused verification, update `plan.md`, summarize the result, and stop so the user can verify it.
- Continue with another item only after the user explicitly asks.
- If a request does not map clearly to one plan item, clarify the intended boundary before making broad changes.
